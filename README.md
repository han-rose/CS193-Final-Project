CS193 Final Project

This project will be a website full of small games to play online with your friends in person together.

## The Problem

I want to create a website that me and my friends can play a couple different games on together. Not all of my friends can just hop onto a Steam game or anything at the drop of a hat, but we do hang out in person a lot together. I think it could be fun to play together like a multiplayer game using one keyboard.
